Built on Monoku's initiative template, with two handover tables, a decisions table and a status that runs through to measured added. Grey text under each field is a prompt, not a rule. Leave anything that doesn't apply and it won't appear in the output.

When you're done, press the button at the bottom. It gives you a markdown file to attach in Slack, so nothing gets mangled between here and Linear.
