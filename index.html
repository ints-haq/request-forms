1 · Who is asking

So the code can be traced back to a person and a decision later.

A named person who has agreed to give this money away. It can be you if it is your budget and your call. This is a record, not a hurdle.

2 · What it is for

One or two lines. Enough that someone reading the Shopify list in six months knows what this code was.

Who gets this code and how they will meet it. A room of people at an in-person event behaves very differently from an email list.
Leave blank only if it genuinely should never expire. Almost every code should have an end date.
Under five working days there may not be time to test properly or build a landing page. Say what is driving the date so the right corners get cut.

3 · The offer

What the customer actually gets.

A number only. 25 means 25% off.
Anything on the site is simplest and what almost every Kismet code does. Restricting to certain products means anyone who adds the wrong item sees the code fail at checkout, which generates support tickets.
Letters and numbers, no spaces. Short is better because people read it off a card or a screen. Write it here exactly as it will appear on every piece of artwork.
Get this exactly right. If the code on the artwork does not match the code in Shopify, every customer sees an error and nobody can fix it from a shop floor or a printed card. Check the spelling against anything already designed before you send this.

4 · Who can use it, and how often

These four choices are where discounts usually go wrong. The notes under each say what it means in real money.

A cap is a safety valve. If a public code reaches a coupon site it can run for weeks before anyone notices. A cap set generously above expected volume costs nothing and stops the worst case.

5 · Where it is going

This decides whether anything needs building alongside the code.

Tick everything that applies. Print and in-person matter most, because those cannot be corrected after the fact.
Printed or in-person. Send this form before anything goes to a printer. Once artwork is printed the code cannot change, and a mismatch between the artwork and Shopify means every customer sees an error on the day.
An auto-apply link and a QR code take minutes. A landing page needs copy, imagery and sign-off, so flag it as early as you can.

6 · Anything else

Anything that does not fit above. Partner requirements, wording they have asked for, things you are unsure about.
